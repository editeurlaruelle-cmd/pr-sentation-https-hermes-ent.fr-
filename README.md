# pr-sentation-https-hermes-ent.fr-
Présentation du projet

Le site https://hermes-ent.fr/
 est un ENT (Espace Numérique de Travail) développé dans un cadre de School RP, avec pour objectif principal de servir de support d’entraînement pour les développeurs.

Ce projet a été pensé comme un environnement simple et accessible permettant de s’exercer sur différentes technologies web telles que HTML, CSS, JavaScript et PHP. Il ne s’agit pas d’un produit final complexe, mais d’un espace évolutif où chacun peut expérimenter, tester des idées et améliorer ses compétences.

Participer au projet

Si vous souhaitez vous entraîner sur un projet web de ce type, que ce soit pour apprendre, tester ou développer de nouvelles fonctionnalités, vous êtes les bienvenus.

N’hésitez pas à me contacter si vous souhaitez contribuer ou proposer des idées. Toute participation est la bienvenue et sera un vrai coup de pouce pour faire évoluer le projet.
